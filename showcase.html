zmn-commit-push

v1.0

规范化 Git 提交流水线。从分支名提取需求编号，读取 diff 自动总结改动点，组装团队规范 commit message，用户确认后一键 push；覆盖冲突、无远程分支等异常。

Git 工作流自动摘要确认检查点

smart-code-review

v1.0

高信号代码审查。四维度加权审查（逻辑 / 安全 / 性能 / 可维护），只报有触发场景、有具体修复方案的问题；疑点必须验证后再下结论，拒绝风格类噪音。

质量门禁多维审查证据驱动

weekly-report-gen

v1.0

周报自动生成。从 git 提交记录按需求聚合产出，区分已完成 / 进行中 / 风险求助；结果导向、拒绝流水账与编造，每条产出都有据可查。

Git 数据汇总需求聚合结果导向

release-guard

v1.0

发布守卫。上线三件套：语义化升版本 → 生产分支附注 tag → 构建归档回滚包；含发布前置检查、发布日志登记与回滚预案，确保每次发布可追溯、可回滚。

发布安全Tag 管理回滚预案

🏗️ 工程方法论 把工程纪律编码为 Agent 行为

systematic-debugging

v1.0

系统化调试五阶段法。复现 → 定位 → 根因 → 修复 → 验证；强制先复现再动手，禁止盲改试错与表象修复，输出结构化调试报告。

根因分析二分定位反盲改约束

tech-decision-adr

v1.0

技术选型决策框架。澄清约束 → 候选方案 → 加权对比矩阵 → 事前验尸（Pre-mortem）→ 产出标准 ADR 文档，让架构决策可追溯、可复盘。
